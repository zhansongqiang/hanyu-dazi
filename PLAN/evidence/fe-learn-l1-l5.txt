## 第三轮：字段对齐核对（本路五页，静态，**零写入**）

第一轮全是 HTTP 层，第二轮是「单根 + 零 CDN」。这一轮补本项目最高频的一类 Bug：
**页面读的字段名 ≠ 接口真发的字段名** —— 症状是列空白 / 卡片显示 0，且**不报错**。
方法：从 `api/*.ts` 的 interface 取「契约 key 集合」，再从五页源码里抽出**每一个**
「响应对象 / 数组元素」的字段读取，逐个求差集。
**全程只读文件：未起服务、未调接口、未新增冒烟数据**（本轮 0 次写入，冒烟账不增）。

- `page.evaluate` 的四个坑（本路踩过并已规避，复核者若重写脚本会遇到）：
  ① **只序列化函数源码** ⇒ Node 侧模块常量与同级助手函数**都带不进浏览器**，
