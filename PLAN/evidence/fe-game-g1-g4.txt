## 逐条对照 §8 的验收标准

**G1「所有数字来自一个 `GET /profile/summary`，不是 N 个请求凑」**
- 接口侧：一次请求返回 `user / xp / streak / rank / stamps / learn / todayCheckedIn` 七块，实测一次到位。
- 前端侧：`mobile/src/pages/profile/profile.vue` 里取数点只有 `loadSummary()` 一处调 `profileApi.summary()`；
  `doCheckin()`（用户手动动作）完成后也是**复用同一个 summary 刷新**，没有追加第二个请求。
  自检命令：`grep -n "profileApi\.\|api\." mobile/src/pages/profile/profile.vue`。
- 打卡后数字确实跟着动（`xp.total 0→5`、`streak.current 0→1`、`todayCheckedIn false→true`、
  `weekRank null→2`）—— 说明它不是把某几个值写死的。

**G2 排行榜**：`rank/week` 的四块（`weekStart/weekEnd/list/me`）与 §4.6 逐字一致；
行 7 字段（`rank,userId,nickname,avatarUrl,weekXp,rankName,isMe`）逐字一致；
`limit=1` 生效；`me` 在榜内时给（此例两人都在榜内；「本周 XP 为 0 未上榜 → `me:null`」这一支
第一轮**没造出来**，已在下面的「第二轮补测」里造出来并实测通过）。
`rankName` 按**累计** XP 判段位、`weekXp` 按本周求和 —— 注入 505 后 `rankName` 从「童生」跳「秀才」（阈值 500），
与 §4.5 的段位表一致。

**G3 印章页未得的章也要显示**：`GET /stamps` 返回 **15 条，全部 15 条 `earned:false`**——
即「一个都没得」时不是空数组，未得的章带着 `earned:false / unlockedAt:null` 照样下发，前端据此画灰态。
行键恰好 §4.7 的 7 个字段。

**G4 打卡与连击**：第一次 `created:true, currentStreak:1, xpEarned:5`；
**重复打卡 `created:false` 且 code 仍为 0（不报错），连击停在 1** —— 幂等成立，
且一天只有一条 `checkins`（`POST` 走的是 `user_id + check_date` 查重）。

## 第二轮补测（2026-11-23 22:52）—— 补 G4 跨天连击与 G2 榜外 `me`

第一轮漏掉了 G4 验收标准里最要紧的那条语义：验收标准写的是「打卡后连击 **+1**」，
而第一轮只观测到 `0→1`（人生第一次打卡）与同日幂等 —— 真正的「+1」（跨天 `1→2`）没测。
本轮用**同一种隔离实例**（8099）补上，脚本 `.smoke-streak.ts`，跑完即删。

**方法（重要，别误读）**：连击的判定只看 `user_streaks.last_checkin_date` 与 `daysBetween()`，
所以"历史上打过卡"这件事**直接写库构造**，不是真等一天。脚本里把注入的假历史原样打印出来了。
三个场景各用一个新注册的账号，互不干扰。

### 判定

- **G4 跨天 +1 成立**：昨天(`2026-11-22`)打过、`current_streak=1` → 今天打卡得
  `currentStreak:2`。且这个 2 **真的流进了 XP 备注**（`note="连续打卡第 2 天"`），
  说明连击值是这一趟算出来的，不是从哪儿读出来的旧值。
- **G4 断签归 1 成立**：上次打卡在 3 天前（`gap=3 > 1`）→ `currentStreak` 从 5 归 **1**，
  但 **`maxStreak` 保留 5**（历史最好成绩不清零）—— 这正是 `max(max_streak, current)` 的预期行为。
- **G4 同日幂等在新账号上同样成立**：B 的第二次打卡 `created:false`、`xpEarned:0`、连击不变。
- **G2 榜外 `me:null` 成立**：全新账号（本周 0 XP）`GET /rank/week` → **`me:null`**，
  且**确实不在 `list` 里**（`limit` 默认与 `limit=200` 各测一次都是 `false`），
  不是"在 list 里但 me 忘了填"。榜上当时有 4 人（其他泳道的取证账号），本路一个没动。
