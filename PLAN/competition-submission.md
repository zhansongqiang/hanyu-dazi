## 三、作品简介（限 300 字）

> 实测 **287 字**（含标点与英文字母，`node` 量的四段正文拼接后长度），限 300 字，余 13 字。

「汉语搭子」是一款面向来华留学生的中文课后陪练 App。它不教新课，只解决课上完之后那一段：把刚学的知识练到手上，一天一刻钟。

同一批知识点用认字、拼音、词义、笔顺、听音五种问法轮着练；汉字有米字格描红，28 个常用字带笔顺演示。答错不惩罚，反而立刻给出正确答案与字源解释，并自动进错题本——错题本会算总账、找规律、开处方，连续答对两次才算真的掌握。

游戏化刻意做轻：答错也给经验，断签不清零，段位只升不降。8 人学习小组、免注册异步 PK、每周排行榜，让一个人也能练下去。

现有 20 课时、308 道题、80 个知识点，覆盖六单元；已打包为 Android 安装包 v0.1。

### 录屏路线（已选 A 并执行完毕）

1. **发货 APK 当时录不了** —— 它烤的 API 源是 `https://hanyu.zj17z.cn`，该域名 2026-11-24 时**还不解析**
   （等加 A 记录 `→ 114.132.232.60`）。直接录发货包会录到一片加载失败。
2. **选定并执行的路线 A｜本地后端验证包**：独立产物目录 `mobile/dist-capp-local/`，构建时
   `VITE_API_ORIGIN=http://10.0.2.2:8091`（`10.0.2.2` 是模拟器回指宿主机的固定地址），
   并 `CAP_ALLOW_MIXED=1` 打开 `allowMixedContent`。这条路线自足、不依赖 DNS。
   - 录的是 **debug 包**（`assembleDebug`）：`debug/` 源集的 network-security-config 给 `10.0.2.2`
     开了明文豁免，`debuggable=true` 才让 WebView 的 devtools socket 可连 —— 二者缺一录不了。
   - 驱动通道是 **CDP over adb**：`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>`
     → `/json/list` → WebSocket → `Runtime.evaluate` / `Input.dispatchTouchEvent`。
     `Input.dispatchTouchEvent` 产生的是**可信事件**，和真手指等价。
     ⚠️ 每次冷启动 App，渲染进程 pid 都会变，`attach` 必须重做。
3. **路线 B｜先上线再录发货包** 仍然可行（加 DNS → 部署 → 录真发货件），但成片已定稿，不重录。
4. **录完已把工程回烤成发货态**（2026-11-25 实测）：**不带** `CAP_WEB_DIR` / `CAP_ALLOW_MIXED` 跑一次
   `npx cap copy android`，实测 `android/app/src/main/assets/public` 里的 API 源从 `10.0.2.2:8091`
   变回 `hanyu.zj17z.cn`，`assets/capacitor.config.json` 的 `webDir` 回到 `dist-capp`、
   `allowMixedContent` 回到 `false`。
   这一步不能省：验证包态若留在工程里，下一次 `assembleRelease` 会打出一个**指向模拟器回环地址
   且允许明文**的发货件 —— 而且它照样能装、照样能启动，只是所有请求都打空。

`adb shell screenrecord` 单次上限 180 秒，正好卡住「1–3 分钟」；但它**不录旁白**，要配音得后期合成或用 scrcpy。
另外录屏前必须 `adb shell settings put global hide_error_dialogs 1`：CDP 注入能绕过系统弹窗，
真手指绕不过 —— 不清弹窗会录进一块「应用无响应」的对话框。
